## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Premature requirement completion | Multiple executors ran `requirements mark-complete` per plan frontmatter, flipping PREP-xx to complete when only a slice shipped; reverted twice (commits 4585789, in 05-02). | advisory | Every executor prompt must include "DO NOT edit .planning/REQUIREMENTS.md checkboxes / do not run requirements mark-complete"; completion is decided only at end-of-phase gsd-verifier. |
| Regex over-match on resource tagging | Tagging "chicken stock" as instant_pot also hit "Pull chicken stock for gravy" (a logistics pull step); had to revert. | advisory | When bulk-writing steps by name match, ALWAYS print the matched steps and guard cook-verbs vs pull/store/distribute before writing. |
| PB 0/"" defaults read as "filled" | PocketBase number fields default to 0 and text/select to "" (not null); the null-only backfill check reported all 185 steps done ("all caught up"), and the editor load-path clobbered saved metadata with undefined on save. | advisory | Use `isStepUnbackfilled` (step-level "any real metadata" check) not per-field null; load the 7 metadata fields into RecipeEditor node.data. Both fixed (1315e49, f2b1071). |
| Mid-phase build breakage from RED tests | `tsc -b` (npm run build) type-checked *.test.ts that import later-wave modules, breaking the build between waves. | advisory | tsconfig.app.json now excludes *.test.ts (Vitest still runs them). Keep that exclusion. |
