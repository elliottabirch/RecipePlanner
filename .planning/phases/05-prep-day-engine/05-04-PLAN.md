<task type="auto">
  <name>Task 2: Draft metadata for all ~185 steps into step-backfill-draft.json</name>
  <files>recipe-planner/src/data/step-backfill-draft.json</files>
  <read_first>
    - .claude/skills/recipe-import/SKILL.md (draft-then-review conventions; controlled prep vocabulary)
    - 05-CONTEXT.md D-05 (resource enum, oven_temp_f required for oven, rack_slots default 1) and the prep_action vocabulary (sliced/diced/minced/chopped/grated/shredded)
    - 05-RESEARCH.md Pitfall 4 (drafts are estimates; review gate is human — aim for reasonable, not perfect)
  </read_first>
  <action>
    Using the Task-1 export, draft metadata for every step OFFLINE (this executor acts as the recipe-import-style drafter — no runtime LLM client is added to src/). For each step infer: active_minutes and passive_minutes (a braise is mostly passive; a dice is mostly active — active occurs before passive, A2), instructions (short imperative sentence), prep_action (only for prep steps, from the controlled 6-verb list), resource (oven/stovetop/blender/food_processor/instant_pot/none inferred from step name + prep_action), oven_temp_f (only when resource=oven), rack_slots (default 1). Write a single JSON object/array keyed by recipe_steps.id. Work recipe-by-recipe (batches) and commit incrementally if needed to bound context. Every resource/prep_action value MUST be a member of the Plan-01 select enums. Do NOT invent fields; do NOT draft lead_time_minutes (D-02). Skip drafting for a step only if it is already fully populated (record it with a skip flag so the review page shows 0 items for it).
  </action>
  <verify>
    <automated>cd recipe-planner && node -e "const d=require('./src/data/step-backfill-draft.json'); const arr=Array.isArray(d)?d:Object.values(d); const R=new Set(['oven','stovetop','blender','food_processor','instant_pot','none']); const P=new Set(['sliced','diced','minced','chopped','grated','shredded']); if(arr.length<100) throw new Error('too few drafts: '+arr.length); for(const e of arr){ if(e.resource&&!R.has(e.resource)) throw new Error('bad resource '+e.resource); if(e.prep_action&&!P.has(e.prep_action)) throw new Error('bad prep_action '+e.prep_action); if(e.resource==='oven'&&e.oven_temp_f==null&&!e.skip) throw new Error('oven step missing temp'); } console.log('draft ok', arr.length)"</automated>
  </verify>
  <acceptance_criteria>
    - step-backfill-draft.json contains an entry for every non-skipped existing step, keyed by recipe_steps.id.
    - Every resource value ∈ the 6-member resource enum; every prep_action ∈ the 6-verb vocabulary.
    - Every oven-resource draft carries an oven_temp_f.
    - No lead_time_minutes field present anywhere in the draft.
  </acceptance_criteria>
  <done>A complete, vocabulary-valid offline draft exists for Plan 08's review page to consume.</done>
