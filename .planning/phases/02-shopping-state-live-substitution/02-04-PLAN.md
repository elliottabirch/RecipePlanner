  <behavior>
    - createSyncQueue({ process, maxAttempts=3, baseDelayMs=1000, onChange }) returns { enqueue(key, payload), pending, failed }.
    - enqueue for a key with an in-flight write coalesces: the newest payload replaces the pending one; process is not double-invoked concurrently for the same key.
    - process resolves → pending decrements; onChange fires with new counts.
    - process rejects → retries after baseDelayMs * 2^attempt; after maxAttempts rejections the key moves to failed (retry-exhausted), pending decrements, onChange fires; the payload is not lost silently.
    - A successful retry after earlier failures clears that key from failed.
    - Injectable timer/clock (or accept a scheduler param) so tests run without real timers (use vitest fake timers).
  </behavior>
  <action>

Implement coalesce-by-key (Map of pending payloads + Set of in-flight keys), exponential backoff (`baseDelayMs * 2 ** attempt`) capped at `maxAttempts`, and pending/failed counters surfaced via getters plus an `onChange(counts)` callback so the hook can drive `SyncIndicator` (Saving = pending>0; retry-exhausted = failed>0; Synced = both 0). Keep it dependency-free and React-free. Make timers injectable (default to setTimeout) so tests use vitest fake timers deterministically.
