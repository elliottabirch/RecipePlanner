<objective>
Eliminate the positional-key correctness hazard (D-01) that blocks persisting the stored/pull/container Outputs tabs. Thread a content-derived `lineId` onto the three data shapes that currently reach their tab components with no stable identity, collapse the three dead-code helper signatures to `(lineId: string)`, and update all four inline call sites to use them.

Purpose: This is the precondition for persisting all six Outputs tabs (D-01). Without it, this phase's own make-it action (`handleAddRecipeToPlan`) reorders index-keyed lists and a persisted positional key would silently re-attach a check to a *different* item — a correctness bug, not a benign reset.
Output artifacts produced by this plan: `StoredItem.lineId`, `PullListItem.lineId`, `MealContainer.containers[].lineId`; reworked `getStoredCheckboxKey`/`getPullListCheckboxKey`/`getContainerCheckboxKey` (single `lineId` param); the four tab components calling them; `aggregation-lineid.test.ts`.
</objective>
