<objective>
Remove the `unit`-as-container-type overload (DATA-03). Stop the RecipeEditor from stuffing the container-type name into `recipe_product_nodes.unit` for stored products; thread the real container name through the aggregated product from `products.container_type`; switch `aggregation.ts` container reads to the new field; and convert the editor's node unit input from free text to an enum-bound Select (§4.7). Implements D-01 (container stays product-level).

Purpose: DATA-03 + D-01. One field can't be a unit enum while also holding container names — this removes the overload so the units work (Plans 03/05) operate on clean semantics.
Output: containerTypeName threading, RecipeEditor write-split + enum Select, consumer audit.
</objective>
