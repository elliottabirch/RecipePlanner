## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| localStorage-at-module-load | `src/lib/pocketbase.ts` → `db-config.ts` reads `localStorage` at module load. A top-level `import "../api"` in a pure lib module crashes the vitest node env AND any plain node script. | advisory | Keep `src/lib/*` pure; `await import("../api")` INSIDE functions. For PB scripts, use the pocketbase SDK directly (`new PocketBase(url)`) — do NOT import `buildRecipeGraph` in node. |
| publish-a-revision-draft | Hitting RecipeEditor "Publish" on a draft with `revision_of` set mints a duplicate published recipe (new id), orphaning planned_meals. | advisory | Revision drafts must be approved via the evolve-recipes WRITE-BACK (onto the original id), never plain publish. Finding #3 below is the fix. |
